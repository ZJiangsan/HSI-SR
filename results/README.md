# Result summaries

This directory contains compact numerical outputs from the experiments reported in the manuscript.

## Reconstruction

- `rgb_only_result.json`
- `rgb_plus_802_result.json`
- `rgb_resolution_x2_result.json`
- `rgb_resolution_x4_result.json`
- `rgb_resolution_x8_result.json`

Ground-truth HR-HSI metrics in these JSON files are **post hoc diagnostics**. They were not used for training, stopping, or checkpoint selection.

## Per-band analysis

- `per_wavelength_bgr_vs_bgr_plus_nir.csv`
- `visible_nir_summary.csv`
- `plot_sensor_summary.csv`

## Downstream functional transfer

- `fold_metrics.csv`
- `cross_fold_summary.csv`
- `experiment_metadata.json`

The prediction model was trained only on genuine Mjolnir HSI and then frozen before evaluation on genuine, RGB-only, and RGB+802 inputs. The split was five-fold GroupKFold by parent experimental plot.

`test_predictions.csv` is generated by `scripts/07_restrans21_40band_5fold.py` and is intentionally not required for the compact result archive.
